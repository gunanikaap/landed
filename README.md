# Landed 🛬

**Ask your job-search pipeline anything, in plain English.**

Landed is a small AI application that turns natural-language questions
(*"what's my response rate, referral vs cold apply?"*) into SQL, runs it
against a real database, and answers you in words — showing the SQL it wrote
and the results.

It's a worked example of putting an LLM **on top of data**: retrieval (RAG)
for grounding, an **agentic tool-use loop** for running queries, and a thin UI.
Built on a synthetic job-search dataset, but the pattern works on any
operational dataset.

## How it works

```
your question
   → retrieve relevant schema + glossary  (RAG, grounding)
   → LLM writes SQL and calls the run_sql tool   (agentic tool use)
   → query runs on DuckDB  (read-only)
   → LLM reads the rows and writes the answer
   → UI shows: answer + SQL + result table
```

## Stack
- **Python**
- **DuckDB** — embedded analytics database
- **Claude** via Anthropic API *or* AWS Bedrock (switchable in `.env`)
- **sentence-transformers** — local embeddings for RAG *(added at the RAG step)*
- **Streamlit** — the UI

## Data
`sample_data/` holds a fully **synthetic** pipeline (no real people or private
data) generated by `scripts/generate_seed_data.py`. To use your own tracker,
keep the same column names and drop the CSVs into a (git-ignored) `real_data/`.

Tables: `companies`, `applications`, `contacts`, `events`.

## Run it
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# build + test the data layer (no API key needed)
python -m landed.db

# (next) configure your LLM and ask questions
cp .env.example .env   # then add your key
```
